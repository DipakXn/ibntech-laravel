Both modules are available to administrators and authors. Neither has a gated PDF download route.

## Press release

1. Open **Content → Press Releases → New**.
2. Set title, slug, category, status, publish date, and featured image.
3. Add content blocks and SEO.
4. Save and preview.

Public URLs:

- Index: `/pressrelease/`
- Detail: `/pressrelease/{slug}/`

## White paper

1. Open **Content → White Papers → New**.
2. Set title, slug, category, status, publish date, and featured image.
3. Add content blocks and SEO.
4. Save and preview.

Public URLs:

- Index: `/whitepapers/`
- Detail: `/whitepapers/{slug}/`

White papers are ordinary published pages. If a paper needs a gated file, use an eBook instead. eBooks are the module with a PDF download endpoint.
